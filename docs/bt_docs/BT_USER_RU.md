# Bluetooth (QCC5125) — инструкция для пользователя lstepMOD

Версия прошивки с BT: **lstepMOD v0.8.202** и новее (при `USE_BT_I2S` в `myoptions.h`).

## Что это

Радио умеет три режима источника звука:

| Режим | Откуда звук | ЦАП |
|-------|-------------|-----|
| **WEB** | Интернет-станции (ESP декодирует) | ES9038 через I2S от ESP |
| **SD** | Файлы с SD-карты | ES9038 через I2S от ESP |
| **BT** | Телефон/ПК по Bluetooth на модуле **QCC5125** | ES9038 через I2S от BT (селектор 74HC157) |

В режиме BT ESP **не декодирует** музыку — только переключает тракт и управляет громкостью/паузой на модуле (GPIO KEY).

---

## Проверка, что BT включён в прошивке

В браузере откройте: `http://<IP-радио>/variables.js`

Должно быть: **`var btSupported=1;`**

Если `btSupported=0` — прошивка собрана без `USE_BT_I2S` или залита старая.

После обновления прошивки залейте **LittleFS** (обновлённые `script.js`, `player.html`, `style.css`).

## WebUI — как переключать режим

На главной странице плеера, **нижняя панель** (`#playernav`), рядом с эквалайзером — кнопки режима (как раньше WEB↔SD, теперь цикл из трёх):

```
WEB  →  SD  →  BT  →  WEB  → …
```

| Сейчас активен | Видна кнопка | Действие по нажатию |
|----------------|--------------|---------------------|
| WEB (радио) | иконка «папка / SD» (`#modeweb`) | переход в **SD** |
| SD | иконка «глобус / WEB» или шаг к BT (`#modesd`) | переход в **BT** (если `btSupported=1`) или в **WEB** |
| BT | иконка BT (`#modebt`) | переход в **WEB** |

Переключение идёт по WebSocket (`newmode=0|1|2`), на ESP выполняется в фоне (как SD), страница не должна «умирать».

### Что видно в режиме BT

- В строке **#meta**: «Bluetooth — ожидание сопряжения» (или title с прошивки).
- Нет плейлиста станций, битрейта, shuffle SD.
- Кнопка **эквалайзера** затемнена — цифровой EQ ESP к BT не применяется.
- Слайдер **громкости** работает: шлёт команды на модуль BT (GPIO VOL+/VOL−), не на I2S ESP.

### Play / Stop в WebUI

В BT — импульс на **KEY Play/Pause** модуля QCC5125, а не запуск интернет-станции.

## Дисплей и тач

- **Дисплей**: заголовок «Bluetooth» (или аналог из `setTitle`).
- **Тач** (верхняя полоса): тот же цикл **WEB → SD → BT → WEB**, что и кнопка режима на вебе.
- **Кнопка MODE** на корпусе (если есть): `changeMode()` по кругу.

---

## Как слушать музыку по Bluetooth

1. Переключите устройство в режим **BT** (WebUI, тач или кнопка).
2. На телефоне/ПК откройте Bluetooth и подключитесь к **колонке QCC5125** (имя зависит от прошивки модуля).
3. Запустите музыку на телефоне — звук идёт **BT → селектор → ES9038**.

Сопряжение (pairing) выполняется **на модуле QCC5125** (кнопка на модуле / его прошивка). Отдельной кнопки Pair в WebUI пока нет.

## Громкость и EQ

| | WEB / SD | BT |
|---|----------|-----|
| Громкость WebUI / кнопки | Цифровая (ESP / I2S) | Импульсы **VOL+ / VOL−** на QCC5125 |
| Эквалайзер WebUI | Работает | **Отключён** (поток не через декодер ESP) |

Уровень в UI сохраняется в конфиге, но в BT это ориентир для вас, не «цифровая» громкость потока ESP.

## Аппаратные пины (текущий `myoptions.h`, v0.8.202)

Заданы **не пересекаются** с I2S ES9038 (5,6,7), soft-I2C ES9038 (15,16), WAKE/IR (4), SLEEP (18) и с типовой разводкой **NV3041A + GT911** (3,8,21,38,39–42,45,47,48):

| Назначение | GPIO |
|------------|------|
| SEL 74HC157 | **2** |
| I2S MCLK (ESP → селектор) | **11** |
| KEY Play/Pause | **12** |
| KEY VOL+ | **9** |
| KEY VOL− | **10** |

При включении **NV3041A** на плате — сверьте разводку; при конфликте измените пины в `src/myoptions.h` и пересоберите.

**SD** для режима SD и переключения режимов: `SDC_CS=39`, SPI `41,42,40`.

## Возврат к интернет-радио

Нажмите кнопку режима до **WEB** (из BT — одно нажатие на `#modebt`) и выберите станцию в плейлисте.

## Устранение неполадок

| Симптом | Что проверить |
|---------|----------------|
| Нет третьей кнопки / `btSupported=0` | `USE_BT_I2S 1` в `myoptions.h`, пересборка + LittleFS |
| Режим BT не переключается | `SDC_CS` не 255 (нужен `changeMode`), Serial: `[changeMode]` |
| Нет звука в BT | SEL, MCLK, прошивка QCC5125, осциллограф BCLK/LRCK/MCLK |
| Громкость в BT не меняется | Проводка KEY 9/10/12, общий GND 3.3 V |
| Щелчок при смене режима | Пауза перед SEL, порядок stop → переключение SEL |
