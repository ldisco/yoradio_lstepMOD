# Bluetooth (QCC5125) — инструкция для WebUI и управления

**Прошивка:** lstepMOD с `USE_BT_I2S` в `src/myoptions.h`  
**Аудиотракт:** ESP (WEB/SD) или BT-модуль → селектор 74HC157 → ES9038

---

## 1. Когда BT доступен в интерфейсе

В браузере откройте: `http://<IP-радио>/variables.js`

- `var btSupported=1;` — режим BT в WebUI **включён**
- `var btSupported=0;` — прошивка без BT (только WEB ↔ SD)

После смены прошивки обязательно залейте **LittleFS** (обновлены `script.js`, `player.html`, `style.css`).

---

## 2. Переключение режимов

### WebUI (страница плеера)

В нижней панели (`#playernav`), рядом с эквалайзером — кнопки режима (как для SD):

| Сейчас | Видна кнопка | Действие |
|--------|--------------|----------|
| **WEB** (интернет-радио) | иконка «SD / папка» (`modeweb`) | переход в **SD** |
| **SD** | иконка «WEB / глобус» (`modesd`) | переход в **BT** |
| **BT** | иконка BT (`modebt`) | переход в **WEB** |

**Цикл:** WEB → SD → BT → WEB → …

Нажатие отправляет на ESP команду `newmode=0|1|2` (переключение в фоне, как при смене SD).

### Тач (если включён дисплей с тачем)

Короткий тап по **верхней полосе** экрана — тот же цикл режимов.

### Кнопка MODE на корпусе

Если в прошивке есть `EVT_BTNMODE` — циклическая смена режима (как раньше WEB↔SD, при BT — три режима).

---

## 3. Что видно в режиме BT

- Строка **meta:** «Bluetooth — ожидание сопряжения» (или title с дисплея).
- Скрыты: плейлист WEB, битрейт, shuffle SD.
- Плейлист **не загружается** (нет станций CSV в BT).
- Кнопка **эквалайзера** затемнена — цифровой EQ ESP к BT **не применяется**.
- Класс `#playernav.bt` — отдельное оформление панели.

---

## 4. Как слушать музыку в BT

1. Переключите устройство в режим **BT** (WebUI / тач / кнопка).
2. На **телефоне или ПК** подключитесь по Bluetooth к модулю **QCC5125** (как к колонке).
3. Запустите музыку на телефоне — звук идёт **BT → селектор → ES9038**, декодер ESP не используется.

Сопряжение (pairing) выполняется **на модуле QCC5125** (кнопка на плате модуля / его прошивка). Отдельной кнопки «Pair» в WebUI пока нет.

---

## 5. Громкость и Play/Pause

| Элемент | В WEB/SD | В BT |
|---------|----------|------|
| Слайдер / Vol± в WebUI | Цифровая громкость I2S ESP | Импульсы на GPIO **VOL+ / VOL−** модуля QCC5125 |
| Play / Stop | Станция / файл | Импульс на GPIO **PLAY** модуля |
| Эквалайзер | Работает | Недоступен (затемнён в UI) |

Уровень громкости в настройках сохраняется для **отображения**; в BT реальная громкость — на стороне BT-модуля.

---

## 6. Возврат к интернет-радио

1. Нажмите кнопку режима до **WEB** (из BT — одно нажатие на `modebt`).
2. Выберите станцию в плейлисте или нажмите Play.

ESP переключит селектор обратно на **I2S от ESP** и восстановит pinout (в т.ч. MCLK при `BT_USE_MCLK`).

---

## 7. Пины по умолчанию (myoptions.h)

Заданы **без пересечения** с NV3041A/GT911 (3, 4, 8, 21, 38–42, 45, 47, 48), I2S (5–7), ES9038 I2C (15–16), SLEEP (18), WAKE/IR (4):

| Назначение | GPIO |
|------------|------|
| SEL 74HC157 | **2** |
| KEY PLAY | **9** |
| KEY VOL+ | **10** |
| KEY VOL− | **14** |
| MCLK ESP (WEB/SD) | **12** |

При разводке платы сверьте с реальной схемой и при необходимости поправьте `src/myoptions.h`.

---

## 8. Диагностика

- Serial: `[changeMode] DONE: BT mode` при входе в BT.
- Нет звука в BT: проверьте SEL, питание QCC5125, MCLK/BCLK на осциллографе, сопряжение телефона.
- Нет кнопки BT в WebUI: `btSupported=0` или старый LittleFS — перепрошейте FS и обновите страницу (Ctrl+F5).
